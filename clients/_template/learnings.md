# Learnings

The Dot writes here after every edit or skip. Every draft after that must follow it.
You can edit or delete any lesson. A lesson you delete is not allowed to come back.

Format of each lesson:

```
### L-<n> · <short title>
- Rule: <one sentence the Dot must follow from now on>
- Applies to: <category or playbook, e.g. "objection replies", "sequence copy", "all drafts">
- Learned from: <edit | skip | batch> on <YYYY-MM-DD>
- Example change: <generic before → after, e.g. "3 sentences → 1 sentence; removed link">
- seen: 1 · last_seen: <YYYY-MM-DD>
- superseded_by: <L-n or none>
```

Precedence: voice/tone.md hard rules > this file > examples.md.
Never write a lead's name, email or company into a lesson.
